# Home для LG webOS 3.5

Домашний экран для LG 49SJ810V, webOS 3.5 (06.10.65), на HTML/CSS и ES5 JavaScript. Без фреймворков, сборщика и npm-зависимостей. Интерфейс, Montserrat Light/Bold, исходный плейлист и логотипы известных каналов входят в IPK.

## Разработка и сборка

```sh
npm start
npm run check
npm test
npm run package
```

Предпросмотр: http://127.0.0.1:8080/. Макет 1920×1080 масштабируется с сохранением пропорций. Браузерный предпросмотр требует работающего локального сервера; установленное приложение загружает интерфейс без интернета.

Пакет: `dist/com.custom.webos.home_0.6.5_all.ipk`. Для сборки нужен установленный LG CLI с `ares-package`. Подключение к ТВ и учётные данные настраиваются отдельно и не входят в репозиторий. Автозапуск описан в AUTOSTART.md.

## Управление

- Стрелки, указатель и колесо выбирают элементы; OK / Enter открывает выбранный пункт.
- Back / Escape закрывает текущую страницу или плеер и восстанавливает фокус.
- Красная кнопка на странице приложений или каналов добавляет / удаляет избранное. В браузере — клавиша R. Контурная звезда обозначает избранное.
- Для перестановки на главной удерживайте указатель 550 мс и перетаскивайте плитку либо удерживайте OK, используйте ← / → и подтвердите OK. Back отменяет перестановку.
- P+/P− / ChannelUp/Down / PageUp/Down переключают каналы в плеере. Поддерживаются коды 33/34 и 427/428; физическая передача этих кнопок на webOS 3.5 ещё требует проверки.

На главной отображается только избранное. При первом запуске начальное избранное — настроенные приложения и исходные HD-каналы. На страницах «Все приложения», «Все каналы», «Все источники» доступны полные каталоги. На ТВ приложения перечисляются через `applicationManager/listApps`; в браузере показываются настроенные и сохранённые приложения.

## Плейлисты и воспроизведение

На странице каналов первая вкладка — «Избранное», далее вкладки документов M3U. Исходный документ: [белорусскоязычный плейлист iptv-org](https://iptv-org.github.io/iptv/languages/bel.m3u). Можно добавить именованный плейлист по HTTP/HTTPS-ссылке или вставить текст M3U. Нужны записи EXTINF с HTTP/HTTPS-адресами потоков. Плейлисты включают SD и каналы с неизвестным разрешением. Одинаковые адреса в разных документах объединяются в каталоге; принадлежность каждой вкладке сохраняется.

Удаление плейлиста убирает его вкладку и каналы, которых больше нет в других документах. URL-плейлисты сохраняются снимком; пользовательские URL автоматически не обновляются. Исходный документ обновляется при запуске и восстановлении сети. Для загрузки ссылок нужен доступный источник и разрешённый CORS; если запрос заблокирован, можно вставить M3U текстом.

На rooted-ТВ также поддерживается папка `/var/lib/webosbrew/custom-home/playlists/`. Каждый файл `.m3u` или `.m3u8` создаёт вкладку с именем файла. Загрузить файл можно через SFTP либо командой `node tools/tv-upload-playlist.js "/путь/к/списку.m3u" tv` (нужны Node.js и настроенный LG CLI). Загрузчик проверяет контрольную сумму, сохраняет резервную копию заменяемого файла и атомарно обновляет его. Содержимое личных плейлистов не входит в репозиторий и IPK.

Папка проверяется при запуске и открытии страницы каналов; кнопка «Обновить из папки» запускает проверку вручную. Во время IPTV импорт отложен. Ограничения: до 32 файлов, 1 МиБ на файл и 2 МиБ суммарно; символические ссылки игнорируются. Последний корректный список кешируется для работы офлайн. Ошибки чтения или некорректная замена не стирают рабочий кеш. Удаление вкладки скрывает её, сохраняя файл; изменение файла добавляет вкладку снова. Удаление самого файла убирает вкладку после успешной проверки папки. Файлы в этой папке сохраняются независимо от переустановки Home; избранное и скрытие вкладок пока остаются в localStorage.

Плеер использует нативный `<video>` и HLS, без hls.js. Совместимость зависит от кодеков, TLS, CORS, региона и самого источника. Предварительный запрос master playlist при фокусе ограничен 2,5 секунды, не задерживает открытие и выбирает подходящий вариант от 720p, если он указан. При ошибке выбранного варианта плеер возвращается к исходному адресу. Видео останавливается при закрытии и скрытии приложения. Полупрозрачный текст «Назад» появляется при движении указателя и скрывается через 2,2 секунды.

Фоновая проверка потоков работает с параллелизмом 2 и приостанавливается на время воспроизведения. Подтверждённые HTTP-ошибки отключают запуск плитки; CORS, тайм-аут и отсутствие сети дают неизвестный статус. В каталоге проблемный канал всё равно можно выбрать для изменения избранного. Успешная загрузка сегмента не гарантирует совместимость декодера ТВ.

## Заставка бездействия

Через 2 минуты бездействия запускается полноэкранная Aerial-заставка. Нажатие на часы запускает её сразу; часы также выбираются стрелками / Tab и активируются через OK. В предпросмотре есть дополнительная клавиша S. Любая клавиша, колесо или движение указателя закрывают заставку и возвращают фокус. Первое действие пробуждения и повтор удерживаемой клавиши не открывают элементы под заставкой.

Используются прямые HTTPS-ссылки Apple, один нативный `<video>` без звука и подпись места. На ТВ приоритет — 4K SDR HEVC, далее 1080p HEVC и 1080p H.264; в браузерах без заявленной HEVC-поддержки — H.264. HDR не выбирается. Манифест Apple — [sylvan.apple.com/Aerials/2x/entries.json](https://sylvan.apple.com/Aerials/2x/entries.json); небольшой совместимый снимок метаданных включён в aerial-assets.js на основе [каталога Aerial Views](https://github.com/theothernt/AerialViews/blob/master/app/src/main/res/raw/tvos26.json). Сами видео принадлежат Apple; приложение не включает и не записывает их файлами. Это сжатое H.264/HEVC-видео, а не несжатые оригиналы.

Обновление JSON выполняется только при запуске заставки, не чаще недели после успеха; ошибка сети / CORS не мешает использовать встроенные ссылки. Кешируются только проверенные метаданные. До запуска заставки видео не предзагружается. При ошибках или длительном зависании пробуется следующий формат / ролик, не более шести последовательных попыток. После этого, а также офлайн, работает экран с часами и периодическим сдвигом их положения. Потоковый буфер контролируется нативным движком; ограничение его размера в байтах из JS не задаётся.

Заставка не запускается во время IPTV, ввода плейлиста и перестановки плиток. При уходе из приложения / потере видимости поток и таймеры останавливаются. На время заставки отменяются проверки IPTV и подготовка его потоков. Это локальная функция Home, не замена системной заставки для YouTube, HDMI или других приложений.

Параметры в `app/config.js`: `screensaver.enabled`, `screensaver.idleMs` (120000), `screensaver.loadTimeoutMs` (12000). Совместимость форматов: [спецификация LG webOS 3.5](https://webostv.developer.lge.com/develop/specifications/video-audio-35). На физическом ТВ новая заставка пока не проверена; встроенный браузер предпросмотра вернул MediaError 4 на MOV и показал запасной экран с часами.

## Настройки и офлайн

Данные пока хранятся только в `localStorage`; отдельный постоянный файл на ТВ не реализован. Существующие ключи сохранены:

| Ключ | Содержимое |
| --- | --- |
| `home.favorites.v1` | Избранные ID приложений, URL каналов, метаданные дополнительных приложений |
| `home.order.apps` / `home.order.channels` | Стабильный порядок плиток |
| `home.playlists.v1` | Пользовательские M3U и их названия / исходные URL |
| `home.playlists.hideDefault.v1` | Удаление исходной вкладки |
| `home.iptv.bel.v1` | Последний загруженный исходный M3U |
| `home.weather.v1` | Последний прогноз Минска |
| `home.aerial.catalog.v1` | Метаданные Aerial: ID, подписи и ссылки Apple; без видео |
| `home.aerial.favorites.v1` | ID выбранных заставок Apple. Пустой список включает только часы |

Часы используют время устройства и UTC+3. Погода запрашивается у Open-Meteo; свежий прогноз повторно не скачивается при возвращении на экран. Логотипы известных каналов берутся из локальных файлов, остальных — из `tvg-logo`, с буквенным запасным вариантом. Браузер и ТВ имеют разные хранилища. Очистка данных / переустановка может удалить настройки.

HDMI 1 — PlayStation 4, HDMI 2 — Mobile Device. USB появляется при обнаружении внешнего накопителя и открывает системное Photo & Video. Наличие сигнала HDMI не определяется. Полный цикл подключения USB ещё нужно проверить на ТВ.

## Архитектура и проверка

Границы модулей, ограничения движка и результаты оптимизации описаны в [ARCHITECTURE.md](ARCHITECTURE.md). Тесты проверяют M3U, доступность потоков, порядок, кнопки переключения, восстановление настроек, ошибки хранилища и согласование списка установленных приложений.

Проверены браузерная навигация, избранное, вкладки плейлистов и восстановление настроек. Проверка ES5 включает запрет объявлений функций внутри условных блоков: старый движок LG отклоняет такой код в строгом режиме. Автозапуск через стартовый вход проверен полной перезагрузкой ТВ; детали и отмена — в [AUTOSTART.md](AUTOSTART.md).

## Настройки и предпросмотр Apple Aerial

Шестерёнка рядом с часами открывает каталог из 139 заставок с локальными миниатюрами. Красная кнопка добавляет или удаляет выделенный ролик из избранного; в браузере ей соответствует R. Клик или OK открывает видеопредпросмотр справа, каталог остаётся в двух столбцах. Крестик и Back закрывают предпросмотр. Под видео показаны название, оригинальное название, время суток и тип сцены. Пустое избранное включает в режиме ожидания только часы.

Предпросмотр предпочитает 1080p H.264. Локальный транспорт `aerial-stream.js` слушает только 127.0.0.1:9765, принимает только ID из встроенного каталога и передаёт Apple-поток с MP4-совместимыми брендами контейнера и корректными Range-запросами. Закодированные кадры и смещения не меняются; перекодирования и сохранения роликов нет. На ТВ транспорт запускается по требованию через Homebrew Channel и завершается после минуты простоя; открытый предпросмотр поддерживает его работу. `npm start` запускает транспорт вместе с предпросмотром на 8080.

Параметры заставки приложения не скрывают ранний системный CoverUI «Home / Загрузка» на webOS 3.5. Системный CoverUI не изменён.

На старом ТВ транспорт использует отдельный публичный Mozilla CA bundle и официальный Apple Root CA (`aerial-ca.crt`), полученный с [официального сайта curl](https://curl.se/docs/caextract.html). Проверка TLS остаётся включена, системное хранилище сертификатов не меняется. Лицензия MPL 2.0 включена рядом с набором.

Логотипы избранных: если исходная картинка не загрузилась после трёх попыток или отсутствует, Home ищет однозначное совпадение в независимой коллекции [tv-logo/tv-logos](https://github.com/tv-logo/tv-logos). Сопоставление учитывает название, транслитерацию и страну из tvg-id; неоднозначные варианты пропускаются. Только на rooted-ТВ, по одному поиску за раз, только для видимых избранных каналов. PNG кешируются в `/var/lib/webosbrew/custom-home/channel-logos/` (до 128 картинок, до 512 КиБ каждая), каталог обновляется раз в неделю. При ошибке сети используется сохранённый каталог. Коллекция предназначена для личного использования; автор — tv-logo/tv-logos. Полнота покрытия не гарантируется.

Сохранённые замены логотипов имеют приоритет перед интернет-ссылкой при запуске. В главных рядах избранных приложений/каналов и во вкладке «Избранное» каналов порядок меняется удержанием левой кнопки мыши около 0,55 секунды и перетаскиванием карточки; отпускание сохраняет порядок. На пульте — удержание OK, стрелки влево/вправо, OK для сохранения и Back для отмены.
