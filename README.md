# Home для LG webOS 3.5

Первая версия домашнего экрана на HTML, CSS и JavaScript без фреймворков, сборщика, npm-зависимостей, внешних шрифтов и изображений. Целевой телевизор — LG 49SJ810V, webOS 3.5 (06.10.65). Все ресурсы интерфейса входят в пакет.

## Предпросмотр на Mac

```sh
npm start
```

Открыть http://127.0.0.1:8080. Макет 1920×1080 масштабируется целиком с сохранением пропорций. Окно 16:9 лучше всего соответствует экрану ТВ. Приложение можно также открыть напрямую через `app/index.html`; для запроса погоды предпочтителен локальный сервер.

- Стрелки: переход между плитками и рядами.
- Enter / пробел: открыть выбранный пункт.
- Мышь / указатель: выбор наведением, запуск кликом.
- Колесо: последовательный обход плиток.
- Escape / Back (461): закрыть настройки или вернуться к первой плитке.
- Tab / Shift+Tab: обход элементов; внутри настроек фокус ограничен диалогом.

В браузере запуск приложения или HDMI показывает уведомление предпросмотра.

## Установочный пакет

Требуется установленный LG CLI с `ares-package`:

```sh
npm run check
npm run package
```

Результат: `dist/com.custom.webos.home_0.1.0_all.ipk`.

Установка и автозапуск пока не выполнялись. При следующем подключении нужно определить реальные ID установленных приложений. Начальные ID намеренно пустые; их можно задать в `app/config.js` или в настройках на экране. Настройки сохраняются в localStorage и имеют приоритет над config.js. Запуск выполняется через `PalmServiceBridge` → `luna://com.webos.applicationManager/launch`. Для HDMI подготовлены ID `com.webos.app.hdmi1` … `com.webos.app.hdmi4`; их работа и разрешения требуют проверки на этом телевизоре. Статус подключения отдельных HDMI пока не определяется.

## Погода и офлайн

Погода: [Open-Meteo](https://open-meteo.com/), координаты центра Минска. Запрос при открытии, возвращении на экран, восстановлении сети и каждые 30 минут. Тайм-аут 10 секунд. Последний успешный ответ сохраняется локально; при сбое показываются сохранённые данные и их возраст. До первого успешного запроса вместо температуры отображается прочерк. TLS и CORS необходимо проверить на старом движке ТВ. Часы используют время устройства, пересчитанное в UTC+3.

Установленный IPK не требует интернета для загрузки интерфейса. Браузерный предпросмотр требует работающего локального сервера (service worker не используется). Надпись о сети отражает `navigator.onLine`, а не проверку доступности интернета.

## Совместимость и проверки

Код написан в стиле ES5, использует XMLHttpRequest и Flexbox; без Promise, fetch, модулей, CSS Grid, blur и фонового видео. [LG указывает Chromium 38 для webOS 3.x](https://webostv.developer.lge.com/develop/specifications/web-api-and-web-engine).

Проверены синтаксис JS, сборка IPK, отображение на Mac, загрузка реальной погоды, стрелки, Enter, диалог настроек, возврат фокуса и Escape; ошибок браузерной консоли при проверке не было. На физическом ТВ не проверены производительность, Magic Remote, Luna-разрешения, запуск приложений, HDMI, TLS и сохранение данных после перезапуска. Полноценное тестирование отсутствия сети на ТВ остаётся до подключения.

## IPTV на главном экране

Все 15 записей исходного [белорусскоязычного плейлиста iptv-org](https://iptv-org.github.io/iptv/languages/bel.m3u) включены в `app/channels.m3u`. Список обновляется при запуске и восстановлении сети, успешный ответ кешируется; при недоступности источника работает локальная копия. На главном экране показываются только 11 записей с указанным разрешением от 720p. Варианты с 576p и без указанного разрешения скрыты. Фильтр опирается на название в плейлисте, а не на замер реального потока. Логотипы из tvg-logo сохранены в app/logos и включены в IPK, чтобы работать офлайн; для новых каналов используется URL из плейлиста. Если изображение недоступно, показываются первые буквы названия. Название канала отображается под логотипом.

Каналы доступны горизонтальным рядом: стрелки влево/вправо прокручивают его, вверх/вниз переключают ряды. Enter или клик открывает встроенный полноэкранный `<video>`. Back / Escape закрывает плеер, освобождает поток и возвращает фокус. Плеер занимает всю область экрана, без стандартных controls, заголовка и панели действий. Единственная кнопка «Назад» появляется при движении указателя и скрывается через 2,2 секунды бездействия. Back / Escape работает всегда, CH+/CH− (427/428) переключают каналы, OK повторяет запуск при остановленном видео. Только ошибки выводятся отдельным сообщением. При скрытии приложения эфир останавливается.

Используется нативное воспроизведение HLS, без hls.js. Возможность просмотра зависит от движка, кодеков, TLS, ограничений региона и доступности источника. Sport TV в текущем списке использует прямой MPEG-TS, его совместимость отдельно требует проверки. Наличие канала в списке не подтверждает доступность эфира. На Mac проверены загрузка всех 15 записей, открытие плеера, возврат фокуса и навигация. После упрощения плеера на Mac подтверждено воспроизведение Belarus-1 (readyState=4, событие playing); в одном измерении старт занял около 9,6 секунды. В HLS этого источника наблюдались сегменты 9,6–12 секунд. Скорость на физическом ТВ не измерена. Тесты парсера: `npm test`.

### Запуск IPTV

При фокусе или наведении на плитку выполняется предварительный запрос HLS master playlist (тайм-аут 2,5 секунды). Если CORS разрешён и запрос успел завершиться, выбирается видеовариант от 720p с наименьшим заявленным битрейтом. Результат используется до 45 секунд; при ошибке воспроизведения этого адреса выполняется возврат к исходному master URL. Прямое открытие канала никогда не ожидает предварительный запрос. При отсутствии CORS или подходящего варианта выбор качества остаётся нативному плееру. Тяжёлые видео заранее не скачиваются, одновременного воспроизведения нет. Убрана лишняя перезагрузка load() перед play(). Первое playing логируется как IPTV first frame; это оценка готовности воспроизведения, а не аппаратный замер вывода кадра. Длительность буфера нативного плеера и сегментов источника из JavaScript не меняется.

## Проверка доступности каналов

При загрузке, восстановлении сети и каждые пять минут на главном экране выполняется фоновая проверка, не более двух HTTP-запросов одновременно. Проверяются HLS-плейлист, вложенный видеоплейлист и получение первых байтов актуального сегмента; скачивание сегмента затем отменяется. Подтверждённые HTTP-ошибки, некорректные/пустые плейлисты повторно проверяются через секунду. Подтверждённо недоступные плитки становятся disabled и пропускаются при навигации. При открытии эфира проверки останавливаются. Получение данных не гарантирует совместимость кодеков: ошибка самого видеоплеера также отключает канал. CORS, сетевой сбой или тайм-аут означают неизвестный статус и не блокируют плитку. Статусы не записываются навсегда; повторная проверка может восстановить доступность. Автотесты охватывают HTTP, CORS, офлайн, повтор, ограничение параллелизма и отмену.

ID Лампы (`lampa.tv`), YouTube AdFree (`youtube.leanback.v4`) и Homebrew Channel (`org.webosbrew.hbchannel`) подтверждены на ТВ по SSH и прописаны в config.js.

## Версия 0.2: приложения, порядок и источники

Оригинальные иконки шести приложений скопированы с этого ТВ и включены в пакет: Лампа, YouTube AdFree, Homebrew Channel, Apple TV, Кинопоиск и Spotify. Проверены ID новых приложений: com.apple.appletv.web, com.685631.3411, spotify-beehive. HDMI 1 подписан PlayStation 4, HDMI 2 — Mobile Device; HDMI 3/4 скрыты. USB появляется только при наличии внешнего USB-накопителя в attachedstoragemanager/listDevices и открывает системное приложение Photo & Video; проверка каждые 15 секунд и при возвращении в Home. На момент проверки накопители не подключены; прочитан реальный ответ API, поведение подключения нужно проверить с флешкой.

Для перестановки приложений и каналов удерживать кнопку указателя 550 мс, перетащить и отпустить. Также можно удержать OK, затем перемещать стрелками влево/вправо и подтвердить повторным OK; Back отменяет изменения. Порядок хранится отдельно для приложений и каналов по стабильным ключам, сохраняется после перезапуска и обновления плейлиста. У каналов крупнее логотипы, без фона карточек, названия меньшим шрифтом; успешная проверка не выводит дополнительную подпись. Сообщения показываются только при проблеме/неопределённом результате проверки.

Убраны надписи «Ваше пространство», «Всё любимое. На одном экране.» и заголовок «Избранное». Индикатор сети салатовый, при отсутствии сети — оранжевый. В пакет включены статические Noto Sans Regular и Medium с кириллицей и SIL OFL (app/fonts/LICENSE.txt), чтобы система не подменяла интерфейсный шрифт на ТВ. Статический TTF не требует поддержки вариативных шрифтов. Небольшие различия сглаживания между ТВ и Mac возможны.
