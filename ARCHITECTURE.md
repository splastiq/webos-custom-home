# Архитектура приложения

Цель — простые границы ответственности без дополнительных зависимостей и накладных расходов на webOS 3.5 / Chromium 38. Скрипты ES5 загружаются в явном порядке в index.html. Новые библиотеки, runtime-загрузчик, сборщик, fetch и полифилы не добавлены.

## Модули

| Модуль | Ответственность |
| --- | --- |
| storage.js | Чтение / запись JSON, единое поведение при недоступном или заполненном localStorage |
| playlist-parser.js | Чистый разбор M3U, безопасные URL, устранение дубликатов документа |
| playlist-store.js | Документы плейлистов, сохранение, объединённый каталог и индексы принадлежности |
| playlists.js | Вкладки, формы импорта / удаления, загрузка URL и отмена запроса |
| favorites.js | Избранное, проверка схемы сохранённых данных, применение видимости домашней полки |
| apps.js | Перечисление приложений ТВ и согласование домашнего каталога с установленными ID |
| tiles.js | Единая фабрика плитки приложения и обработка изображения / запасной буквы |
| platform.js | Граница PalmServiceBridge, тайм-ауты и освобождение системных запросов |
| iptv.js | Каталог плиток каналов, подготовка / воспроизведение и жизненный цикл потока |
| channel-health.js | Ограниченные по параллелизму отменяемые проверки HLS и сегментов |
| library.js | Полноэкранные страницы, фильтрация, фокус, действия пульта и точечное обновление статуса |
| order.js / remote.js | Стабильный порядок, перетаскивание, переключение каналов |
| widgets.js | Часы, сеть и погода с независимым жизненным циклом |
| aerial-catalog.js / aerial-assets.js | Проверенные ссылки Apple, форматы и небольшой кеш метаданных |
| idle.js | Независимый таймер бездействия с приостановкой и ручным запуском |
| screensaver.js | Жизненный цикл одного беззвучного видео, ограничение повторов, пробуждение и запасные часы |
| main.js | Сборка интерфейса, домашняя навигация, HDMI / USB |

Чистые модули storage / playlist-parser / playlist-store / remote / функция упорядочивания можно тестировать без браузера. Состояние доступности потока принадлежит плееру, не изменяет кеш модели плейлистов. Системные API доступны только через platform.js. Текст и метаданные создаются через textContent, без HTML из M3U.

## Оптимизации

- M3U разбирается при изменении документа. Принадлежность вкладке и начальное избранное проверяются по URL-индексу, без повторного разбора.
- Обновление статуса одного канала использует прямую ссылку на его домашнюю плитку и индекс полноэкранных плиток. Вложенные обходы всего DOM удалены. Пересчёт домашней навигации при смене disabled объединяется через requestAnimationFrame.
- При навигации меняются классы и tabIndex только предыдущей и новой плитки. Обработчики указателя / фокуса / клика делегированы контейнерам вместо трёх обработчиков на каждый элемент.
- Видимые плитки и геометрия полноэкранной сетки кешируются до изменения каталога или вкладки. Логическая ширина макета фиксирована, масштабирование окна не меняет расположение сетки.
- Порядок восстанавливается по индексам за O(n), вместо вложенных indexOf / циклов. Плитки вставляются через DocumentFragment.
- Повторное перечисление приложений не создаёт дубликаты; удалённые с ТВ приложения исключаются из текущего каталога. Ошибка API оставляет сохранённый каталог.
- Часы записывают DOM по границе минуты. Свежая погода не запрашивается повторно при возврате. При скрытии виджеты отменяют запрос прогноза, плеер прекращает эфир и проверки.
- Удалены неиспользуемые Noto Sans (~1,7 МБ исходных TTF); действующий Montserrat остаётся локальным. CSS развёрнут в читаемый вид, перекрытые объявления одинаковых селекторов убраны без перестановки каскада.

## Подтверждения

`npm run check`, `npm test`, `npm run package` должны проходить перед выпуском. Проверка синтаксиса использует один Node-процесс; это не эмулятор Chromium 38. Совместимость ES5 сохраняется при написании кода, а аппаратная проверка остаётся обязательной.

В тесте кеша 5 000 обращений к каталогу и принадлежности не вызывают повторного парсинга. Проверяются повреждённый JSON, неверная схема, отказ записи, откат избранного, сохранение документов при перезапуске, общие потоки и удаление исходной вкладки. Тесты приложений покрывают устаревшие ID, повторное перечисление и абсолютные / относительные пути иконок.

Контрольный замер на Mac в Node: восстановление 5 000 сохранённых ключей в обратном порядке, медиана 5 запусков — до 204,52 мс, после 2,36 мс. Это синтетический замер алгоритма, не обещание аналогичного ускорения всего интерфейса или ТВ.

Браузерная проверка: домашние полки, все три страницы, стрелки и возврат фокуса, добавление / удаление избранного, создание вкладки M3U, восстановление после перезагрузки и удаление тестового документа. Основные вычисленные стили сопоставлены до и после очистки CSS; отличались динамические значения часов, прогноза и статусов.

## Практические ограничения

Каталог пока создаёт DOM-элемент для каждого канала; виртуализация тысяч строк не реализована. Проверка большого плейлиста ограничена двумя запросами одновременно, но может занимать длительное время. Источники без CORS могут воспроизводиться нативно и при этом не допускать JavaScript-проверку.

На rooted-ТВ localStorage является рабочей копией; user-data.js и user-data-store.js атомарно сохраняют данные в /var/lib/webosbrew/custom-home/settings.json и восстанавливают их до загрузки stateful-модулей через startup.js. При ошибке восстановления внешний файл не перезаписывается. Автозапуск на webOS 3.5 настроен через EIM; описание и откат находятся в AUTOSTART.md.

## Заставка 0.4.0

Элемент video находится вне масштабируемого #screen. До бездействия или ручного запуска ему не задаётся src. При выходе pause / removeAttribute(src) / load освобождают ресурс, а токен сессии блокирует устаревшие отказы Promise. Error и rejected play Promise объединяются в одну смену формата. Ввод перехватывается на window capture, до обработчиков пульта приложения; удерживаемая клавиша пробуждения поглощается до keyup. Отпускание OK, которым запущена заставка с часов, не закрывает её.

Тесты idle.js проверяют дедлайн, частую активность указателя без размножения таймеров, исключение IPTV/редактора, ручной запуск и приостановку. aerial-catalog.js проверяет доверенные Apple-хосты, исключение HDR, выбор вариантов, офлайн, CORS, кеш и отмену JSON-запроса. screensaver.js проверяет ручной OK, mute, гонку ошибок, откат форматов, лимит попыток, устаревший Promise, освобождение потока и возврат фокуса. Встроенный предпросмотр не подтвердил реальное декодирование MOV; аппаратная проверка на LG остаётся обязательной.

## Предпросмотр и совместимость 0.5.0

Настройки и отрисовка каталога отделены в settings.js, сохранение избранных ID — aerial-favorites.js, жизненный цикл плеера — aerial-preview.js. Видеослой находится вне масштабируемого #screen и следует физическим координатам слота. Миниатюра скрывается только после появления декодированных кадров.

Встроенный браузер отклонял QuickTime-файлы Apple с MEDIA_ELEMENT_ERROR 4. aerial-stream.js предоставляет локальную потоковую выдачу с нормализацией брендов контейнера. В рабочем браузере подтверждены декодирование 1920×1080 и продвижение времени воспроизведения. Транспорт использует curl, обратное давление потоков, не более четырёх запросов, фиксированный список Apple URL и loopback-интерфейс; первые 20 байт меняются без изменения длины файла, видео-полезная нагрузка остаётся неизменной.
